AI Gateway for Claude Code — decision deck

1 / 5

Requirements

All Claude Code traffic (engineers now, unattended agents later) routed through one gateway. Baseline spend assumption: strong developers average ~$4,000/dev/mo on Claude → 20 devs ≈ $80k/mo, 50 devs ≈ $200k/mo in tokens.

Core

  • AuthN/Z: SSO/OIDC sign-in, per-user virtual keys, per-user and per-group spend + rate limits
  • Metrics: usage & cost per user/team/model, prompt capture — with retention controls (full prompt logs are a liability themselves)
  • Guardrails: PII/secret redaction before egress — in-process, <200 ms comfortable next to multi-second model TTFT; LLM-judge guardrails are too slow for interactive CLI
  • Failover: Anthropic quota exhausted / 429 / 5xx → Bedrock/Vertex PAYG (Claude-family) automatic
  • Budget lane: route cost-insensitive work to Kimi / GLM / DeepSeek Flash tiers (10–30× cheaper than Claude)

Non-obvious must-haves

  • Prompt-cache preservation — a proxy stripping cache_control markers silently re-bills the whole conversation uncached, every turn. At $4k/dev/mo this is the single biggest cost lever.
  • Streaming (SSE) passthrough with usage accounting from stream-end events
  • Key custody: upstream keys in a vault; engineer leaves → revoke one virtual key, not the shared org key
  • Agent identities: unattended agents get separate keys, tighter budgets, own audit trail
  • Audit logs → SIEM, log encryption at rest, retention TTL
  • Latency & HA: <200 ms total added per request (proxy + guardrails) — invisible next to multi-second model TTFT. Gateway down = every engineer blocked, so HA from day 1
“Share subscriptions” is off the table. Pooling Pro/Max OAuth quotas through a gateway violates Anthropic ToS and is technically enforced since early 2026 (server-side rejection of subscription tokens outside first-party products). Legitimate “shared pool”: org-level API keys with Console billing (or Bedrock/Vertex, or Enterprise managed seats) behind the gateway, with per-user attribution and budgets. At $4k/dev/mo usage levels, API billing is the only model that scales anyway.
Why percentage-fee vendors are disqualified at our scale: a 5% markup on $80k/mo token spend = $4k/mo (on $200k/mo = $10k/mo) — more than any flat-priced gateway costs in total. Rule: flat license or self-host only; OpenRouter-style 5% fees only as an emergency backstop.

Claude Code integration & the budget-model lane

What’s officially supported, and how to reach cheaper open-weight models without leaving our compliance boundary.

Supported paths (Anthropic-documented)

  • Claude apps gateway — built into the claude binary. Browser SSO via your IdP, managed settings per IdP group, OTLP usage metrics, spend limits. Upstreams: Anthropic API, Bedrock, Vertex, Foundry. Evaluate first — auth + metrics for $0.
  • Bring-your-own gateway — compatibility protocol is documented; config is env vars pushed org-wide via MDM managed settings:
ANTHROPIC_BASE_URL=https://gw.corp.com
ANTHROPIC_AUTH_TOKEN=<gateway-issued>
ENABLE_TOOL_SEARCH=true
  • Anthropic does not support routing Claude Code to non-Claude models through any gateway — that lane is community practice (right column).

Budget lane — inside our compliance boundary

  • Constraint: only GitHub Copilot, AWS Bedrock, GCP Vertex are approved upstreams. First-party Moonshot/z.ai/DeepSeek endpoints are out.
  • COPILOT — BEST Natively hosts Kimi K3, Kimi K2.7 Code, DeepSeek (older gen) — GitHub-managed on Azure, admin must enable open-weight models. Native Anthropic-compatible endpoint → Claude Code works through the gateway with no translation. LiteLLM has first-class Copilot support (github_copilot/ provider). ⚠ DeepSeek V4.1 Flash appears in Copilot only via BYOK → traffic goes direct to api.deepseek.com, outside the compliance boundary. Caveats: internal token flow (acceptable-use, not SLA'd API), extended thinking dropped, premium requests = AI Credits. Confirm plan coverage with GitHub.
  • GROK 4.6 — ACCEPTABLE ALT $2/$6 per 1M (<200K ctx; ⚠ whole request reprices to $4/$12 past 200K — long Claude Code sessions cross this). ~7× cheaper than Opus, ~2× pricier than GLM 5.3, weaker than Claude at agentic coding. The one non-Chinese frontier-adjacent model available on all three approved vendors (Copilot picker, Bedrock, Vertex) — zero procurement work.
  • BEDROCK serverless PAYG, but several generations late on open-weight models (GLM 4.7 Flash, DeepSeek V3.2, Kimi K2.5 — vs GLM 5.3 / V4.1 / K3 current). Clean metered API on the AWS bill; acceptable for unattended agents that don’t need frontier quality.
  • VERTEX Qwen3-Coder-480B / DeepSeek V3.1 as managed PAYG (also stale); anything newer = GPU self-deploy (ruled out). Its real card is Gemini Flash — very cheap, but weak at agentic coding; last-resort lane.
  • Universal caveats for non-Claude lanes: prompt-cache economics, /cost accuracy, thinking blocks. Opt-in budget lane, never silent default.
Pitch line: premium lane = Claude (supported path, gateway → Anthropic API / Bedrock PAYG failover); budget lane = Kimi K3 / GLM / DeepSeek via Copilot or Bedrock — one auth, one budget system, one audit trail; policy decides who gets which lane.

The build plan — 10 + 10 mandays

Go service, single binary, few dependencies. Day-1 scope is deliberately thin; everything under “later” has a known OSS path when needed.

Architecture

Claude Code / agents→ Go proxy: SSO JWT auth → virtual keys → Redis budget check → guardrail scan → SSE relay→ Anthropic API · Bedrock · Vertex · Copilot
async usage events→ Postgres (user · model · tokens · cost · prompt-ref)→ dashboards + alerts

Build — 10 mandays

  • 2d — HTTP/SSE reverse proxy: streaming byte-relay, usage extracted from stream-end events
  • 2d — auth: SSO-issued JWT → per-user/agent virtual keys; issuance + revocation API
  • 1d — budgets: Redis token-bucket rate limits + daily/monthly spend caps per user & group (429 with a clear message)
  • 2d — metering: per-model price table, cached-token pricing, cost events → Postgres
  • 1d — failover: Anthropic → Bedrock on 429/5xx/timeout, capped retries; premium/budget lane routing
  • 1d — guardrails L1 (in-process Go, ~2–10 ms): Gitleaks detect package as a library (MIT, keyword-prefiltered regex + entropy) for secrets + tuned regex for structured PII (email/phone/SSN/CC+Luhn/IP) → typed placeholders [EMAIL_1]
  • 1d — admin: minimal API/UI for keys, budgets, spend per user/team

Later — known OSS paths, not day 1

  • Guardrails L2 (unstructured PII: names, addresses): local sidecar — GLiNER2-PII (Apache 2.0, best open PII recall, ~20 ms GPU / 50–200 ms CPU) or Presidio (MIT, mature HTTP sidecar). Mandatory on client-data lanes, off on others
  • Reversible redaction: session-scoped placeholder map, buffer-and-flush restore on SSE streams (placeholders can split across chunks) — Uber’s gateway does exactly this at 16M queries/mo
  • Prompt-injection screen: ProtectAI deberta-v3-small via ONNX Runtime’s Go binding — in-process, ~20–60 ms CPU
  • SCIM group sync, SIEM export, semantic cache. ⚠ Avoid TruffleHog embedded — AGPL on a networked service

Rollout — 10 mandays

  • 2d — deploy: 2 replicas behind LB, managed Postgres + Redis, upstream keys in vault, TLS
  • 2d — org-wide config via MDM managed settings (ANTHROPIC_BASE_URL + token) — zero per-dev setup
  • 2d — dashboards & alerts: spend per user/team/model, budget-hit rate, latency/error SLOs
  • 1d — oncall playbook: gateway-down bypass, key-compromise runbook
  • 3d — pilot one team → fix sharp edges → all devs

Explicitly out of scope

  • Polished web UI / self-serve signup — API + MDM is enough for 20–50 devs
  • Multi-region — single region + bypass runbook until agents outnumber humans
  • Universal model translation — lanes are pinned to Anthropic-format upstreams (Anthropic, Bedrock, Vertex, Copilot’s Anthropic endpoint); no translator to maintain

Reality check: the proxy is the easy part. The durable taxes are price-table upkeep, log storage economics (naive full-prompt capture ≈ 14–31 GB/day → tier + sample, $400–900/mo), and provider API churn — that’s what the 0.1–0.25 FTE is for.

Build it. 20 mandays, ~$300/mo to run, and no vendor ever holds our prompts or keys.

Where the gateway is mandatory

  • DAY 1 Unattended agents / CI workflows — subscription OAuth doesn’t exist there anyway; agent identities, tight budgets, full audit from the start
  • DAY 1 Critical-systems development — code that must never leave the governed path
  • DAY 1 Client-data workflows — e.g. prod-incident investigation where logs go into prompts; PII guardrail + prompt logging with retention controls apply
  • UNTIL RENEWAL everyday dev use stays on Claude subscriptions (gateway can front them for metrics); everyone migrates when subscriptions lapse and spend becomes API-billed through the gateway

Model lanes & fallback triggers

  • Premium lane: Claude via Anthropic API, failover to Bedrock PAYG — the supported path
  • Budget lanes: Kimi K3 via Copilot (latest open-weight, in-boundary) · Grok 4.6 as the sanctioned alternative on all three approved vendors · Bedrock GLM/DeepSeek for unattended agents
  • Interim freebie: Anthropic’s built-in Claude apps gateway (SSO, OTLP metrics) can cover attribution while our proxy ships — evaluate in week 0
  • Adopt a vendor instead if: the team can’t hold 0.1–0.25 FTE oncall · an auditor demands a SOC 2’d intermediary · feature drift (SCIM, semantic cache) outgrows the 20-manday scope. Then: Bifrost Enterprise quote first; TrueFoundry if SaaS is acceptable; LiteLLM only pinned + isolated
