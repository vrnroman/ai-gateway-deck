AI Gateway for Claude Code — decision deck

1 / 4

Requirements

All Claude Code traffic (engineers now, unattended agents later) routed through one gateway. Baseline spend assumption: strong developers average ~$4,000/dev/mo on Claude → 20 devs ≈ $80k/mo, 50 devs ≈ $200k/mo in tokens.

Core

  • AuthN/Z: SSO/OIDC sign-in, per-user virtual keys, per-user and per-group spend + rate limits
  • Metrics: usage & cost per user/team/model, prompt capture — with retention controls (full prompt logs are a liability themselves)
  • Guardrails: PII/secret redaction before egress — in-process, <20 ms LLM-judge guardrails are too slow for interactive CLI
  • Failover: Anthropic quota exhausted / 429 / 5xx → Bedrock/Vertex PAYG (Claude-family) automatic
  • Budget lane: route cost-insensitive work to Kimi / GLM / DeepSeek Flash tiers (10–30× cheaper than Claude)

Non-obvious must-haves

  • Prompt-cache preservation — a proxy stripping cache_control markers silently re-bills the whole conversation uncached, every turn. At $4k/dev/mo this is the single biggest cost lever.
  • Streaming (SSE) passthrough with usage accounting from stream-end events
  • Key custody: upstream keys in a vault; engineer leaves → revoke one virtual key, not the shared org key
  • Agent identities: unattended agents get separate keys, tighter budgets, own audit trail
  • Audit logs → SIEM, log encryption at rest, retention TTL
  • Latency budget <50 ms, HA — gateway down = every engineer blocked
“Share subscriptions” is off the table. Pooling Pro/Max OAuth quotas through a gateway violates Anthropic ToS and is technically enforced since early 2026 (server-side rejection of subscription tokens outside first-party products). Legitimate “shared pool”: org-level API keys with Console billing (or Bedrock/Vertex, or Enterprise managed seats) behind the gateway, with per-user attribution and budgets. At $4k/dev/mo usage levels, API billing is the only model that scales anyway.
Why percentage-fee vendors are disqualified at our scale: a 5% markup on $80k/mo token spend = $4k/mo (on $200k/mo = $10k/mo) — more than any flat-priced gateway costs in total. Rule: flat license or self-host only; OpenRouter-style 5% fees only as an emergency backstop.

Claude Code integration & the budget-model lane

What’s officially supported, and where the latest Chinese models actually live (spoiler: not Bedrock/Vertex).

Supported paths (Anthropic-documented)

  • Claude apps gateway — built into the claude binary. Browser SSO via your IdP, managed settings per IdP group, OTLP usage metrics, spend limits. Upstreams: Anthropic API, Bedrock, Vertex, Foundry. Evaluate first — auth + metrics for $0.
  • Bring-your-own gateway — compatibility protocol is documented; config is env vars pushed org-wide via MDM managed settings:
ANTHROPIC_BASE_URL=https://gw.corp.com
ANTHROPIC_AUTH_TOKEN=<gateway-issued>
ENABLE_TOOL_SEARCH=true
  • Anthropic does not support routing Claude Code to non-Claude models through any gateway — that lane is community practice (right column).

Budget lane: latest Chinese models, pay-per-token

  • NOT BEDROCK/VERTEX Bedrock is 1–2 generations stale (Kimi K2.5, GLM 4.7, DeepSeek V3.2); Vertex makes you self-deploy on GPU-hours. Dead end for “latest + pay per token.”
  • FIRST-PARTY APIs Moonshot (api.moonshot.ai), z.ai (api.z.ai), DeepSeek all sell pay-per-token and expose Anthropic-compatible endpoints natively — Claude Code works through the gateway with no translation layer at all.
  • Prices: GLM 5.3 Flash $0.15/$0.50 · DeepSeek V4 Flash $0.22–0.44/$0.66–1.32 per 1M tok (in/out) — 10–30× cheaper than Claude; both strong at coding. Flagships (Kimi K3 $3/$15) are Sonnet-priced — no savings there.
  • DATA RESIDENCY first-party = prompts go to Chinese providers. US-hosted alternative: Fireworks/OpenRouter serve the same open weights at ~+50% premium. Gateway makes this a per-team policy toggle.
  • Degrades behind any non-Claude lane: prompt caching economics, /cost accuracy, thinking blocks, tool-call edge cases. Offer as opt-in budget lane, never silent default.
Pitch line: premium lane = Claude (supported path, gateway → Anthropic/Bedrock PAYG failover); budget lane = Flash-tier Chinese models via first-party endpoints through the same gateway — one auth, one budget system, one audit trail, policy decides who gets which lane.

Recommendation

Adopt, don’t build. Numbers at 20 devs × $4k/mo = $80k/mo token spend.

Phased plan

  • 1 · Week 0: built-in Claude apps gateway for SSO + attribution + metrics. Free, supported, zero vendor review.
  • 2 · Core gateway: Bifrost OSS self-host (clean security record, µs-scale in-process PII, translation core feature). Pay Enterprise only when you need OIDC/SCIM + the Anthropic-passthrough route — likely within a quarter, so get the quote early. Fallback: LiteLLM OSS if you need its breadth — pinned + hash-verified + isolated only. No-ops option: TrueFoundry SaaS $499/mo.
  • 3 · Budget lane: z.ai + DeepSeek first-party keys in the gateway; GLM 5.3 Flash / DeepSeek V4 Flash as opt-in models; Fireworks route for teams with China-data restrictions.
  • 4 · Failover: Anthropic → Bedrock PAYG (Claude-family continuity). OpenRouter only as emergency backstop — its 5% fee ≈ $4k/mo at our scale.
  • 5 · Revisit in-house build only if agent-aware routing or unusual compliance demands it — budget 4–6 eng-months + permanent 0.1–0.25 FTE.

If you build anyway: day-1 quick wins

  • DAY 1 single org upstream key + per-user virtual keys — kills key sprawl instantly
  • DAY 1 per-user daily caps in Redis (429 + clear message)
  • DAY 1 usage log (user, model, tokens, $) → Postgres; raw SSE relay, meter from stream-end usage events
  • DAY 1 failover chain on 429/5xx with capped retries
  • HARD per-model price tables (silent mis-metering on every provider price change — biggest ongoing tax)
  • HARD full-prompt log storage economics (naive ≈ 14–31 GB/day → $9k/mo; tiering + sampling → $400–900/mo)
  • HARD <20ms PII at RPS, SSO groups, tamper-evident audit, provider API churn oncall

Reference: Uber’s in-house gateway serves 30 teams / 16M queries/mo, ~2 engineers — but they mirrored one stable API and accepted PII-redaction latency as deliberate scope cuts.
