AI Gateway for Claude Code — decision deck

1 / 4

Requirements

All Claude Code traffic (engineers now, unattended agents later) routed through one gateway instead of directly to Anthropic.

Core — from your list

  • AuthN/Z: SSO/OIDC sign-in, per-user virtual keys, per-user and per-group spend + rate limits
  • Metrics: usage & cost per user/team/model, prompt capture — with retention controls, because full prompt logs become a liability themselves
  • Guardrails: PII/secret detection + redaction before egress — must be in-process, <20 ms LLM-judge guardrails are too slow for interactive CLI
  • Failover: Anthropic quota exhausted / 429 / 5xx → Bedrock or Vertex PAYG, automatic
  • Translation: serve Claude Code (Anthropic Messages format) from Kimi / GLM / Gemini backends

Gaps worth adding — “something else”

  • Prompt-cache preservation — a proxy that strips cache_control markers silently re-bills the whole conversation as uncached input every turn. Biggest hidden cost driver.
  • Streaming (SSE) passthrough with usage accounting from stream-end events — mid-stream budget kills are painful
  • Key custody: upstream provider keys in a vault, rotation, one engineer leaves → revoke one virtual key, not the shared org key
  • Agent identities: unattended agents get separate keys, tighter budgets, own audit trail
  • Audit logs → SIEM, log encryption at rest, configurable retention TTL
  • Latency budget: <50 ms added, HA — gateway down means every engineer blocked
“Share subscriptions” needs re-framing. Pooling Pro/Max OAuth quotas across engineers through a gateway is a ToS violation — and Anthropic has technically enforced it since early 2026 (server-side rejection of subscription tokens in third-party contexts). The legitimate patterns: API keys with Console billing, Enterprise managed seats, or Bedrock/Vertex billing. The gateway then gives you the “shared pool” feeling via org-level keys + per-user attribution.
Claude Code / agents→ gateway: auth · budget · PII scan · log→ Anthropic API/ fallback → Bedrock · Vertex · Kimi · GLM

LiteLLM — what actually happened

  • Mar 24 2026 — PyPI supply-chain breach (TeamPCP): poisoned litellm 1.82.7/1.82.8, credential stealer + systemd backdoor, ~47K downloads in-window; victims incl. NVIDIA, Deloitte. Root cause: stolen PyPI token via compromised Trivy/Checkmarx CI Actions.
  • 2026 CVE chain: pre-auth SQLi (exploited within 36 h), unauth RCE (CVSS 10, CISA KEV), MCP auth bypass (CISA KEV), host-header auth bypass.
  • Footguns: historically unauthenticated by default; sk-1234 default master key accepted by ~10% of internet-exposed instances (Wiz).
  • Compliance scandal: SOC 2/ISO badges came from Delve (accused of fabricating audits); re-certifying via Vanta.
  • Remediation is real (Mandiant forensics, signed releases, rebuilt CI) — usable if pinned + hash-verified + network-isolated, but trust is damaged.

Pattern & what to demand

  • No alternative is spotless — SSRF is the recurring bug class across Bifrost, Portkey, Helicone, TensorZero — but none match LiteLLM’s density of RCE/SQLi/auth-bypass + breach + badge scandal.
  • Avoid for new deployments: TensorZero (shut down Jun 2026), Helicone (maintenance mode after Mintlify acquisition; ignored an SSRF disclosure).
  • Demand: self-host or ZDR tier, SOC 2 Type II verified with the named auditor, encrypted log/key storage, no default-open auth, signed releases + pinned hashes, responsive CVE handling, egress hardening (deny link-local/metadata endpoints).
  • The category is consolidating fast (Portkey→PAN, Helicone→Mintlify, TensorZero dead) — favor a forkable OSS core or a credible acquirer.

Claude Code integration reality

What’s officially supported vs. community practice — this determines which tools even qualify.

Supported paths (Anthropic-documented)

  • Claude apps gateway — built into the claude binary itself. Browser SSO via your IdP, managed settings per IdP group, OTLP usage metrics, spend limits. Upstreams: Anthropic API, Bedrock, Vertex, Foundry. Evaluate this first — it may cover auth + metrics for free.
  • Bring-your-own gateway: Anthropic documents the exact compatibility protocol; LiteLLM, Bifrost, TrueFoundry, Kong, Zuplo, agentgateway known-working. Config is just env vars, distributed org-wide via managed settings (MDM):
ANTHROPIC_BASE_URL=https://gw.corp.com
ANTHROPIC_AUTH_TOKEN=<gateway-issued>
ENABLE_TOOL_SEARCH=true
  • Anthropic does not support routing Claude Code to non-Claude models through any gateway — that path is community territory (below).

Non-Anthropic models (unsupported, mature)

  • First-party Anthropic-compatible endpoints: Kimi (api.moonshot.ai/anthropic) and GLM (api.z.ai/api/anthropic) officially document Claude Code setups — same BASE_URL + AUTH_TOKEN pattern, no translation layer needed.
  • Translation routers: claude-code-router (~26k★, scenario routing, credential pools), LiteLLM /v1/messages, Bifrost. Works well for routine agentic coding.

What degrades behind a translator

  • COST prompt-cache markers stripped → silent full-price re-billing; test /cost per provider
  • ACCURACY /cost token accounting wrong unless proxy synthesizes Anthropic-shaped usage
  • QUALITY thinking blocks, tool-call fidelity (nested schemas, parallel calls), MCP tool search disabled on non-Anthropic hosts
  • MISC Remote Control refuses non-Anthropic base URLs; set every model-tier env var — partial config fails silently
Practical split: keep primary Claude traffic on the supported path (gateway → Anthropic/Bedrock/Vertex). Offer Kimi/GLM/Gemini as an opt-in budget lane via translation for cost-sensitive or experimentation workloads — never as the silent default, because the failure modes above are quiet.

Build vs. buy — and the recommendation

Baseline token spend: ~$150–250/dev/mo for heavy Claude Code use (50 devs ≈ $7.5–12.5k/mo). Gateway cost is small next to that — pick on risk and ops burden.

$0–800/movendor, self-host OSS or hosted team tier (Bifrost/LiteLLM OSS, Portkey $49, Helicone-scale tiers). LiteLLM Enterprise ≈ $30k/yr (est.), Kong $30–120k/yr
3–6 wkin-house MVP: proxy + auth + Redis budgets + Postgres logging + SSE passthrough + failover
4–6 moproduction-grade in-house (HA, <50 ms, price tables, SSO, audit) plus 0.1–0.25 FTE forever

If you build: day-1 quick wins vs. hard later

  • DAY 1 single org upstream key + per-user virtual keys — kills key sprawl instantly
  • DAY 1 per-user daily caps in Redis (429 + clear message); 50-person teams without caps can exceed $10k/mo
  • DAY 1 usage log (user, model, tokens, $) → Postgres; raw SSE byte-relay, meter from stream-end usage events
  • DAY 1 failover chain Anthropic → Bedrock on 429/5xx, capped retries
  • HARD per-model cost accounting — maintained price tables are the biggest ongoing tax; silent mis-metering on every provider price change
  • HARD full-prompt log storage: naive ≈ 14–31 GB/day; tiering + sampling bring $9k/mo → $400–900/mo
  • HARD <20 ms PII scanning at RPS; multi-provider failover with semantic equivalence; SSO groups; tamper-evident audit

Reference: Uber’s gateway serves 30 teams / 16M queries/mo, built by ~2 engineers — but mirroring one stable API and accepting PII-redaction latency were deliberate scope cuts.

Recommendation — adopt, then maybe build

  • 1 · Week 0: evaluate Anthropic’s built-in Claude apps gateway — SSO, per-group managed settings, OTLP metrics, zero new vendor. It may be your auth + metrics layer for free.
  • 2 · Core gateway: self-host Bifrost OSS (Go, µs-scale in-process PII, translation as core feature, clean security record). Budget for Enterprise only if you need the Anthropic-passthrough route + OIDC/SCIM. Alternative: LiteLLM OSS — broader features, but only with pinned/hash-verified installs, network isolation, and acceptance of its 2026 track record.
  • 3 · Hosted shortcut: if self-hosting is the blocker, TrueFoundry or Portkey ($49/mo tier) have documented Claude Code setups — accept the compliance review; verify the auditor.
  • 4 · Failover: Bedrock/Vertex PAYG as the exhaustion lane; OpenRouter BYOK optional as a further backstop (~5% fee).
  • 5 · Defer in-house build. Revisit only if you need agent-aware routing or unusual compliance — and budget 4–6 eng-months + permanent 0.1–0.25 FTE when you do. The proxy is easy; metering tables, log economics, and provider API churn are the real product.
